### Repositorios

**[unsupervised-music-clustering](https://github.com/SaidyB/unsupervised-music-clustering)**
Proyecto de posgrado (Minería de Datos, UNAL). Análisis no supervisado de características de audio en canciones de Spotify para identificar patrones emocionales y de estructura musical. Usé PCA para reducción de dimensionalidad, KMeans y GMM para clustering, y UMAP para visualización. Lo interesante fue ver cómo los algoritmos agrupan canciones de formas que tienen sentido musical real.
`Python · scikit-learn · UMAP · Jupyter`

**[Agenda-Educativa](https://github.com/SaidyB/Agenda-Educativa)**
Agenda educativa construida sobre Google Apps Script con integración en Google Sheets. Automatización de flujos, manejo de datos en tiempo real y una interfaz HTML funcional.
`Google Apps Script · HTML · JavaScript`

**[SportHub-Reservation-System](https://github.com/SaidyB/SportHub-Reservation-System)**
Sistema de reservas para espacios deportivos: gestión de disponibilidad, usuarios y confirmaciones.
`JavaScript`
